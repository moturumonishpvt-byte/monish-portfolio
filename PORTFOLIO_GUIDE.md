### 5. Projects

**Chapter prompt:** “What did I build?”  
**Displayed heading:** “Selected engineering systems” (the interactive project showcase)

The project chapter uses an interactive, 34-card fan-and-wheel presentation. Selecting a project opens a case study with the problem, approach/architecture, technology stack, and impact. The four detailed case studies currently described in the portfolio are:

#### Academic Monitor System

- **Period / role:** Jan. 2026 – Present; Lead Full Stack & AI Architect
- **Purpose:** An offline-first attendance suite intended to reduce proxy attendance without continuous internet access or cloud latency.
- **System:** Three applications for Student, Faculty, and Admin workflows.
- **Student verification:** On-device MobileFaceNet with TensorFlow Lite, 128-dimensional embeddings, and a cosine threshold of 0.60, called through native Kotlin modules.
- **Proximity verification:** RSSI-gated peer-to-peer BLE handshakes with a threshold above -85 dBm and dynamic rolling session seeds.
- **Admin client:** ArcFace ResNet-100 INT8 ONNX with 512-dimensional embeddings; the portfolio reports 52 FPS, 187 ms latency, and 89 MB RAM. It includes an 11-tab admin console, Supabase WebSocket session locks, and Playwright-based ERP synchronization.
- **Reported impact:** Face inference reduced from about 6,000 ms to about 200 ms (25–40x speedup); attendance verification designed to work without continuous internet; automated synchronization with legacy ERP portals.
- **Stack:** React Native, Kotlin, TensorFlow Lite, ONNX, BLE, Node.js, Supabase, and Playwright.

#### Aequitas — AI Bias Mitigation Platform

- **Period / role:** 2026; ML & Backend Engineer
- **Purpose:** Audit and mitigate accent-based bias in automated video/audio interview scoring.
- **Approach:** Evaluate transcripts and scores with Gemma 4 and Perspective API across 200+ applicant profiles; apply post-hoc score calibration; ingest records in 500-record batches into Supabase PostgreSQL; and use SynthID-style cryptographic watermarking for audit verification.
- **Reported impact:** Demographic-parity score variance calibrated to below 7% across the tested profiles, with batch ingestion and tamper-evident audit trails.
- **Stack:** Python, Flask, Gemma 4, Perspective API, Supabase, and Docker.

#### PhishGuard AI — Threat Detection Suite

- **Period / role:** Dec. 2025; AI Security Lead
- **Purpose:** Detect phishing pages and credential-harvesting behavior in real time, addressing the limitations of static domain blocklists.
- **Approach:** A Manifest V3 Chrome extension and FastAPI backend use a 200-estimator Random Forest trained/evaluated on 11,431 URLs with 88 lexical and structural features. A hybrid decision score weights ML at 70% and heuristics at 30%. A browser DOM observer checks for credential-harvesting mismatches, while Levenshtein checks under 2 characters are used against 13 global targets.
- **Reported impact:** Sub-15 ms ML classification is stated in the summary; the case study describes real-time client-side protection and explainable risk breakdowns.
- **Stack:** Python, FastAPI, Scikit-learn, React, Manifest V3 extension, and SQLite.

#### Skill Connect — Campus Collaboration Hub

- **Period / role:** Jan. 2025; Full-Stack Developer
- **Purpose:** Help students and faculty find cross-disciplinary collaborators, form project teams, and assess contributor accountability.
- **Approach:** React and TypeScript frontend with 22 routes; Supabase PostgreSQL with eight relational tables, WebSocket feeds, role-based project matchmaking, and strict Row-Level Security. Database triggers recalculate member reputation after mandatory post-completion peer reviews.
- **Reported scale / impact:** Approximately 4,150 lines of TypeScript; automated peer-review-based reputation recalculation and database protections.
- **Stack:** React, TypeScript, Supabase, Tailwind CSS, and WebSockets.

The case-study entries link to the GitHub profile and display project-specific links where configured. The current project data uses the same GitHub profile URL for the listed repository/live links.

## Visitor-facing interactive features

These are part of the portfolio experience, but are not additional chapters:

- **Chapter navigation:** A floating chapter tracker can jump to the 13 sections; the header also includes a smaller set of section links. A mobile menu is provided for narrow screens.
- **Smooth scrolling and progress:** Navigation scrolls smoothly, and a top progress indicator tracks page scroll.
- **Project showcase and case studies:** The project wheel/fan is interactive; choosing a project opens its detailed case-study modal.
- **Messages Portal:** Available from the header and contact chapter.
- **Monish AI:** A floating AI representative chat offers quick prompts about role availability, the BLE attendance system, technical skills, and awards. It sends chat requests through the site API and has fallback responses for those quick prompts.
- **Preloader and sandbox:** The page has an opening preloader and a separate preloader sandbox control.
- **Visual interaction:** The portfolio includes a custom cursor, ambient canvas visuals, scroll-triggered motion, and an interactive layered hero portrait. Motion behavior is designed with reduced-motion support in applicable components.
