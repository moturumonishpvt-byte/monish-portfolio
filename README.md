* **Skill Connect** — Campus collaboration hub spanning 22 responsive views, 8 Supabase PostgreSQL relational tables, and granular Row-Level Security (RLS) policies.

## Getting Started

### Prerequisites

* [Node.js](https://nodejs.org/) (v18 or higher recommended)
* `npm` or `yarn` / `pnpm`

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/moturumonishpvt-byte/monish-portfolio.git
   cd monish-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` (or `http://localhost:5173`) in your browser.

4. **Production Build:**
   ```bash
   npm run build
   npm start
   ```
